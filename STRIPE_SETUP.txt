OPTIONAL: WEBHOOK SETUP (For Production)
════════════════════════════════════════════════════════════════════════

Webhooks notify your app when payments succeed/fail.

🧪 FOR LOCAL TESTING:
1. Install Stripe CLI:
   https://stripe.com/docs/stripe-cli
2. Run: stripe login
3. Run: stripe listen --forward-to localhost:8501/webhook
4. Copy webhook signing secret (whsec_xxx)
5. Add to .env: STRIPE_WEBHOOK_SECRET=whsec_xxx

🌐 FOR PRODUCTION:
1. In Stripe Dashboard: Developers → Webhooks
2. Click "Add endpoint"
3. URL: https://your-app.com/webhook
4. Events to listen: 
   - payment_intent.succeeded
   - payment_intent.payment_failed
   - customer.subscription.created
   - customer.subscription.updated
   - customer.subscription.deleted
5. Copy webhook secret
6. Add to production .env

════════════════════════════════════════════════════════════════════════
TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════

❌ "Payment features disabled"
   → Check STRIPE_SECRET_KEY is in .env file
   → Restart Streamlit app

❌ "No such customer"
   → Make sure you're using test keys with test data
   → Don't mix test/live modes

❌ "Invalid API key"
   → Check you copied the full key (starts with sk_test_ or sk_live_)
   → No spaces before/after the key

❌ Payment not working
   → Check you created products in Stripe Dashboard
   → Use test card: 4242 4242 4242 4242
   → Check browser console for errors
