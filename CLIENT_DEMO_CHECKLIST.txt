## 🔧 Pre-Demo Checklist

### Configuration
- [ ] Set `STRIPE_SECRET_KEY` in `.env` or Streamlit secrets
- [ ] Set `STRIPE_PUBLISHABLE_KEY` in `.env` or Streamlit secrets
- [ ] Verify database connection (Neon PostgreSQL)
- [ ] Optional: Configure Upstash Redis for caching

### Stripe Dashboard Setup
1. Create account at https://stripe.com/gb
2. Create 3 products in Stripe Dashboard:
   - Starter Plan (£29.99/month, £299/year)
   - Professional Plan (£79.99/month, £799/year)
   - Enterprise Plan (£199.99/month, £1999/year)
3. Copy API keys to configuration
4. Set up webhook endpoint for production

### Demo Account
- Create admin user: `python Retailsights/create_admin.py`
- Test subscription flow with Stripe test cards
- Verify all tabs load correctly

## 📊 Database Schema

### Core Tables
- `users` - User accounts & authentication
- `shops` - Retail locations
- `products` - Product catalog
